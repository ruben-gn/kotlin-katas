# Kotlin-katas

Drie korte refactor-opdrachten in Kotlin (ongeveer 20 minuten elk), voor een gesprek waarin we samen code verbeteren.
De code werkt, maar is niet mooi. Er is geen vast eindresultaat: we zijn benieuwd hoe je denkt.

| Map | Onderwerp |
|---|---|
| `opdracht-invoice-lines` | Factuurregels maken van activaties |
| `opdracht-hourly-averages` | Kwartierwaarden omrekenen naar uurgemiddelden |
| `opdracht-bid-book` | Biedingen verzamelen op een congestieverzoek |

Elke map is een los Gradle-project met een eigen `OPDRACHT.md`.

```sh
cd opdracht-bid-book
./gradlew test
```

Nodig: JDK 21 of nieuwer. Gradle komt via de wrapper.
